# 聊天场景按钮

输入框旁的「管理场景」可新增、修改和删除场景。每个场景包含按钮名称、说明、回答规则和项目资料；通用规则由所有场景共享。初始提供「通用八股」和「算法讲解」，项目资料由用户自行添加。

点击场景按钮后，后续请求只使用通用规则、所选场景规则和该项目资料，通用系统提示词与会话设置共用，选中场景时替代默认用户模板与共享背景。默认配置仍保存，可通过「默认」恢复。聊天历史继续按原会话的历史设置发送。

管理面板中的「切换后重答上一题」默认开启，可关闭并记住偏好。重答复用最近一条用户问题和附件，不重复插入问题。旧回答保存在该问题的「查看旧回答」中，供查看而不发送给模型。生成过程中可再次点击其他场景，中止旧回答并使用最新选择重答；点击已选中的场景或「默认」恢复默认配置。截图回答中也可切换场景；仅截图文件正在采集上传时暂不切换。

每个场景按钮均可拖动，位置保存在当前浏览器。右键单个按钮可复位，管理面板中的「按钮归位」可将全部按钮放回输入框旁。拖动不会触发切换。

场景目录存储于 `data/prompt_scenes.json`，跨会话共享；每个会话保存选中场景的快照。管理面板保存后立即同步当前会话；会话设置里修改当前场景的规则和资料也会更新场景目录。其他会话保留原快照，重新选择可应用新版。删除目录中的场景也不会抹掉会话快照和历史回答。

场景规则和项目资料在构造模型请求时合并到当前用户消息，仅附加一份，不再放入系统消息，也不写入聊天历史。系统消息保留通用系统提示词和公共历史范围规则。后续轮次、重新生成和切换场景都从原始问题构造本轮内容，不累计之前的场景提示词。历史中的原始问题和回答仍按会话设置保留。移动到用户消息不会减少这些文字本次占用的上下文或输入 token。
