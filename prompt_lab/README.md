# 八股回答提示词实验室

这个目录保存提示词模板、批量题库、后台实验执行逻辑和实验结果。

- `prompts.json`：可直接编辑的提示词模板。
- `questions.json`：可直接扩展的八股题库。
- `service.py`：Qwen 批量调用与增量保存。
- `router.py`：前端使用的 FastAPI 接口。
- `data/runs/`：每次实验一个 JSON 文件。每条结果都保存问题、完整提示词快照、实际请求消息、模型参数、回答、耗时、评分和备注。

前端入口为聊天页面顶部的“八股实验室”。单次最多执行 120 个“题目 × 模板 × 模型”组合，默认并发数为 2，防止短时间调用过多。

提示词以快照形式写入实验 JSON，因此以后即使修改 `prompts.json`，历史回答仍然能准确还原当时实际发送的内容。
