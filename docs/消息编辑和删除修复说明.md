# 消息编辑和删除功能修复说明

## ✅ 已修复的问题

### 1. 消息更新 404 错误
**原因**: 前端使用消息索引，后端改为使用消息ID

**修复**: 
- ✅ 前端 `MessageList.vue` - 修改 `saveEdit()` 函数使用消息ID
- ✅ 错误提示改进，显示详细错误信息

### 2. 消息删除 404 错误  
**原因**: 前端传递 `message_indices`，后端期望 `message_ids`

**修复**:
- ✅ 前端 `MessageList.vue` - 修改 `deleteMessages()` 函数
- ✅ 将消息索引转换为消息ID后再发送

### 3. unhashable type: 'dict' 错误
**原因**: `model_info` 在某些情况下是字典而不是对象，无法添加到set

**修复**:
- ✅ 后端 `session_storage.py` - 安全获取model_id
- ✅ 兼容字典和对象两种格式

## 📝 技术细节

### 前端修改 (`frontend/src/components/MessageList.vue`)

#### 1. 消息更新函数
```javascript
// 修改前
async function saveEdit(index) {
  const response = await fetch(`/api/sessions/${sessionId}/messages/${index}`, ...)
}

// 修改后  
async function saveEdit(index) {
  const message = props.messages[index]
  const messageId = message.id || `msg_${index}` // 兼容旧数据
  const response = await fetch(`/api/sessions/${sessionId}/messages/${messageId}`, ...)
}
```

#### 2. 消息删除函数
```javascript
// 修改前
body: JSON.stringify({
  message_indices: indices
})

// 修改后
const messageIds = indices.map(index => {
  const message = props.messages[index]
  return message.id || `msg_${index}`
})
body: JSON.stringify({
  message_ids: messageIds
})
```

### 后端修改 (`backend/services/session_storage.py`)

#### 安全获取模型ID
```python
# 修改前
for msg in session.messages:
    if msg.model_info and msg.model_info.id:
        used_models.add(msg.model_info.id)

# 修改后
for msg in session.messages:
    if msg.model_info:
        # 兼容字典和对象
        if isinstance(msg.model_info, dict):
            model_id = msg.model_info.get('id')
        else:
            model_id = msg.model_info.id
        
        if model_id:
            used_models.add(model_id)
```

## 📋 使用说明

### 编辑消息
1. 鼠标悬浮在消息上
2. 点击"编辑"按钮（铅笔图标）
3. 修改内容
4. 点击"√"保存，或按 `Ctrl+Enter`

### 删除消息
1. 鼠标悬浮在消息上
2. 点击"删除"按钮（垃圾桶图标）
3. 确认删除

### 批量删除
1. 点击右上角"选择"按钮
2. 勾选要删除的消息
3. 点击"删除选中"按钮
