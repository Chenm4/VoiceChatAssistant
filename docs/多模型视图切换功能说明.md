# 多模型视图切换功能说明

## 功能概述

为多模型并行回答添加了灵活的视图切换功能，支持在并排显示和全屏显示之间自由切换。

## 功能特性

### 1. 模型选择按钮组

在多模型回答的顶部，会显示一组模型选择按钮：
- 每个按钮对应一个模型，显示模型名称
- 按钮带有颜色标签，区分不同的模型提供商
- 点击按钮可以切换视图模式

### 2. 三种显示模式

#### 并排显示模式（默认）
- 所有模型的回答并排显示
- 适合快速对比不同模型的回答
- 每个回答卡片都有悬浮操作按钮

#### 单模型全屏模式
- 只显示选中模型的回答
- 回答区域自动扩展到最大宽度
- 选中的模型按钮会高亮显示
- 其他模型按钮变为半透明状态

#### 快速切换
- 点击任意模型按钮即可切换到该模型的全屏视图
- 点击"显示全部"按钮返回并排显示
- 再次点击当前选中的模型按钮也可返回并排显示

### 3. 操作按钮

#### 并排模式下的按钮
- **复制按钮**：复制该模型的回答内容
- **全屏按钮**（展开图标）：将该模型切换到全屏显示

#### 全屏模式下的按钮
- **复制按钮**：复制当前显示的回答内容
- **显示全部按钮**：返回并排显示所有模型

## 使用场景

### 场景 1：快速对比
1. 默认并排显示所有模型回答
2. 一眼看到不同模型的回答差异
3. 适合简短问题的快速对比

### 场景 2：深度阅读
1. 点击模型按钮进入全屏模式
2. 专注阅读某个模型的详细回答
3. 适合长文本内容的仔细阅读

### 场景 3：逐个查看
1. 点击第一个模型按钮查看其回答
2. 点击第二个模型按钮切换到下一个
3. 点击"显示全部"返回对比视图

## 视觉反馈

### 按钮状态
- **未选中**：白色背景，正常显示
- **选中**：蓝色边框，浅蓝背景，高亮显示
- **未选中但在全屏模式**：半透明显示
- **悬停**：轻微上浮，添加阴影

### 卡片状态
- **并排模式**：标准宽度，悬停时轻微上浮
- **全屏模式**：扩展到最大宽度，蓝色边框，更明显的阴影

### 动画效果
- 视图切换有平滑的过渡动画
- 按钮状态变化有渐变效果
- 卡片展开/收缩有流畅的动画

## 技术实现

### 状态管理
```javascript
// 使用对象记录每个消息的全屏模型索引
const fullscreenModelIndex = ref({})

// 示例：
// { 0: 1 } 表示第0条消息的第1个模型处于全屏状态
// {} 表示所有消息都处于并排显示状态
```

### 核心函数
- `toggleModelView(messageIndex, modelIndex)` - 切换模型视图
- `enterFullscreen(messageIndex, modelIndex)` - 进入全屏模式
- `exitFullscreen(messageIndex)` - 退出全屏模式

### 响应式显示
```vue
<!-- 根据状态控制卡片显示 -->
<div 
  v-show="fullscreenModelIndex[index] === undefined || fullscreenModelIndex[index] === modelIndex"
  class="model-message-card"
  :class="{ 'fullscreen-card': fullscreenModelIndex[index] === modelIndex }"
>
```

## 样式设计

### 颜色方案
- 主色调：蓝色 (#3b82f6) - 选中状态
- 辅助色：绿色 (#10b981) - "显示全部"按钮
- 背景色：浅灰 (#f9fafb) - 按钮组背景

### 布局特点
- 按钮组使用 flexbox 布局，自动换行
- 卡片使用 flex 布局，支持响应式宽度
- 全屏卡片宽度设为 100%，充分利用空间

## 兼容性

- 完全兼容现有的单模型消息显示
- 不影响用户消息的显示和操作
- 保持原有的编辑、删除、复制等功能
- 支持选择模式和批量删除功能
