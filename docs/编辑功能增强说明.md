## 📐 编辑框宽度优化

### 2. 编辑框占满屏幕宽度

**修改前**: 编辑框宽度受消息气泡限制（最大 75%）

**修改后**: 编辑模式下，消息气泡自动扩展到 95% 宽度

#### 样式修改

```css

  max-width: 75%;
}

/* 修改后 */
.message-bubble {
  max-width: 75%;

/* 编辑模式下占满宽度 */
.message-bubble:has(.bubble-content.editing) {
  max-width: 95%;
  width: 100%;
}
```

## 🎨 去除渐变紫色

### 3. 将所有渐变紫色替换为蓝色

**修改前**: 使用渐变紫色（#667eea → #764ba2）

**修改后**: 使用蓝色渐变（#3b82f6 → #2563eb）

#### 替换的颜色

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| 渐变色 | `linear-gradient(135deg, #667eea 0%, #764ba2 100%)` | `linear-gradient(135deg, #3b82f6 0%, #2563eb 100%)` |
| 主色调 | `#667eea` | `#3b82f6` |
| 深色调 | `#764ba2` | `#2563eb` |
| 半透明渐变 | `rgba(102, 126, 234, ...)` | `rgba(59, 130, 246, ...)` |

#### 受影响的元素

1. **保存按钮** - 从渐变紫色改为纯蓝色
2. **全选按钮** - 从渐变紫色改为蓝色渐变
3. **模型选择按钮** - 边框和激活状态改为蓝色
4. **编辑框焦点** - 边框颜色改为蓝色
5. **复选框** - 选中颜色改为蓝色
6. **工具栏按钮** - 悬停效果改为蓝色

## 🔧 技术实现

### 1. CSS `:has()` 伪类

使用现代 CSS 特性实现条件样式：

```css
.message-bubble:has(.bubble-content.editing) {
  max-width: 95%;
  width: 100%;
}
```

这样当消息气泡包含编辑中的内容时，自动扩展宽度。

### 2. 批量颜色替换

使用 Python 脚本批量替换颜色：

```python
replacements = [
    (r'#667eea', '#3b82f6'),
    (r'#764ba2', '#2563eb'),
    (r'linear-gradient\(135deg, #667eea 0%, #764ba2 100%\)', 
     'linear-gradient(135deg, #3b82f6 0%, #2563eb 100%)'),
]

for pattern, replacement in replacements:
    content = re.sub(pattern, replacement, content)
```

## 📝 使用说明

### 编辑用户消息

1. 鼠标悬停在用户消息上
2. 点击 ✏️ **编辑**按钮
3. 在编辑框中修改内容
4. 点击 **保存** 或按 `Ctrl+Enter`

### 编辑 AI 消息

1. 鼠标悬停在 AI 消息上
2. 点击 ✏️ **编辑**按钮（新增功能）
3. 在编辑框中修改内容
4. 点击 **保存** 或按 `Ctrl+Enter`

### 取消编辑

- 点击 ❌ **取消**按钮
- 或按 `Esc` 键
