# 重新生成按钮使用说明

## 功能概述

现在已经添加了直接的**重新生成按钮**（🔄），可以快速重新生成消息的响应，无需修改内容。

## 按钮位置

### 用户消息操作栏
将鼠标悬停在**用户消息**（蓝色气泡）上，会显示以下按钮：

```
📋 复制  |  ✏️ 编辑  |  🔄 重新生成  |  🗑️ 删除
```

### AI 消息操作栏
将鼠标悬停在**AI 消息**（白色气泡）上，会显示以下按钮：

```
📋 复制  |  🔄 重新生成此响应  |  🗑️ 删除
```

## 使用方法

### 方式 1：重新生成用户消息的响应

**场景：** 你发现某条用户消息的内容没问题，但想让 AI 重新回答

**步骤：**
1. 找到你想重新生成的**用户消息**
2. 将鼠标悬停在消息气泡上
3. 点击 🔄 **重新生成**按钮
4. 系统会自动：
   - 删除该消息之后的所有对话
   - 使用相同的内容重新发送给 AI
   - 获得新的响应

**示例：**
```
你：介绍一下 Python    ← 点击这里的 🔄 按钮
AI：Python 是一种...     [这条及后续都会被删除]
你：它有什么特点？      [会被删除]
AI：Python 的特点...     [会被删除]
```

重新生成后：
```
你：介绍一下 Python
AI：[新的响应内容]      ← 重新生成的内容
```

---

### 方式 2：重新生成 AI 响应

**场景：** AI 的某个回答不满意，想让它重新回答

**步骤：**
1. 找到你想重新生成的**AI 消息**
2. 将鼠标悬停在消息气泡上
3. 点击 🔄 **重新生成此响应**按钮
4. 系统会自动：
   - 找到这条 AI 消息对应的用户消息
   - 删除该 AI 消息及之后的所有对话
   - 重新生成响应

**示例：**
```
你：介绍一下 Python
AI：Python 是一种...     ← 点击这里的 🔄 按钮
你：它有什么特点？      [会被删除]
AI：Python 的特点...     [会被删除]
```

重新生成后：
```
你：介绍一下 Python
AI：[新的响应内容]      ← 重新生成的内容
```

---

### 方式 3：修改内容后重新生成

**场景：** 你想修改用户消息的内容，然后重新生成

**步骤：**
1. 找到你想修改的**用户消息**
2. 点击 ✏️ **编辑**按钮
3. 修改消息内容
4. 在编辑框下方会看到两个选项：
   - **保存**：只保存修改，不重新生成
   - 或者点击顶部的 🔄 按钮
5. 点击"保存"后，如果你标记了重新生成，会自动触发重新生成

**更简单的方式**（如果已实现）：
- 在编辑模式下，会显示黄色提示框和"保存并重新生成"按钮

## 功能对比

| 功能 | 操作 | 是否修改内容 | 使用场景 |
|------|------|--------------|----------|
| 🔄 重新生成 | 点击用户消息的重新生成按钮 | ❌ 不修改 | 内容没问题，只是想要不同的回答 |
| 🔄 重新生成此响应 | 点击 AI 消息的重新生成按钮 | ❌ 不修改 | AI 回答不满意，想重新生成 |
| ✏️ + 保存并重新生成 | 先编辑，再保存并重新生成 | ✅ 修改 | 需要修正消息内容，并重新生成 |

## 注意事项

### ⚠️ 会删除后续对话

点击重新生成按钮后，**该消息之后的所有对话都会被删除**，无法恢复！

**建议：**
- 在点击前确认你确实想删除后续对话
- 如果担心丢失重要内容，可以先复制保存
- 未来可能会添加"撤销"功能

### ⚠️ 网络请求

重新生成会向 AI 发送新的请求，需要等待响应时间。

### ⚠️ 多模型模式

如果会话配置了多个模型，重新生成会同时调用所有模型，生成多个并行响应。

```

```

```
    递归包含两个关键要素：
    1. 基本情况（Base Case）：递归的终止条件
    2. 递归情况（Recursive Case）：函数调用自身
    
    例如计算阶乘：
    def factorial(n):
        if n == 0:  # 基本情况
            return 1
        return n * factorial(n-1)  # 递归情况
```

## 快捷操作技巧

### 技巧 1：快速尝试不同回答
- 不满意当前 AI 回答？直接点击它的 🔄 按钮
- 可以连续点击多次，快速尝试不同回答
- 每次都会得到不同的响应（由于 AI 的随机性）

### 技巧 2：保留中间对话
如果你想保留部分对话，可以：
1. 先复制想保留的内容
2. 点击 🔄 重新生成
3. 如果需要，粘贴之前复制的内容继续对话

### 技巧 3：对比多个模型
如果配置了多个模型：
1. 发送一条消息
2. 查看所有模型的响应
3. 如果都不满意，点击用户消息的 🔄 按钮
4. 所有模型会同时重新生成新的响应

## 常见问题

### Q: 点击重新生成后可以取消吗？
A: 一旦点击，后续消息就会被删除。目前不支持撤销，建议在点击前确认。

### Q: 重新生成会使用相同的内容吗？
A: 是的，重新生成会使用原消息的完整内容，但 AI 的回答会不同（由于随机性）。

### Q: 可以修改内容后再重新生成吗？
A: 可以，使用"编辑"功能修改内容，然后保存并重新生成。

### Q: 重新生成会用哪个模型？
A: 
- 如果会话配置了特定模型，使用会话配置的模型
- 否则使用全局默认模型
- 如果配置了多个模型，会并行调用所有模型

### Q: 为什么 AI 消息没有编辑按钮？
A: AI 消息有编辑按钮，你可以手动修改 AI 的回答内容（但修改后不会重新生成）。

## 技术说明

### 工作原理

1. **用户消息重新生成：**
   ```
   用户点击 🔄 → 删除后续消息 → 使用原内容重新发送 → 获得新响应
   ```

2. **AI 消息重新生成：**
   ```
   用户点击 🔄 → 找到父用户消息 → 删除该 AI 消息及后续 → 重新生成
   ```

### API 调用

调用的后端接口：
```
POST /api/sessions/{session_id}/messages/{message_id}/regenerate
```

请求体：
```json
{
  "message_id": "msg_abc123",
  "new_content": "消息内容"
}
```
