# 消息管理功能说明

本次更新为应用添加了完整的消息管理功能，包括单条消息的编辑、删除以及批量删除操作。

## 功能概览

### 1. 单条消息操作
- **编辑消息**：点击消息气泡上的"编辑"按钮，可以修改消息内容
- **删除消息**：点击消息气泡上的"删除"按钮，可以删除单条消息
- 操作按钮会在鼠标悬停在消息上时显示

### 2. 批量操作
- **批量模式**：点击顶部工具栏的"批量操作"按钮进入批量选择模式
- **全选**：批量模式下点击"全选"按钮可以选择/取消所有消息
- **批量删除**：选择多条消息后，点击"删除选中"按钮批量删除

## 后端 API 变更

### 新增接口

#### 1. 更新消息
```
PUT /api/sessions/{session_id}/messages/{message_index}
```
请求体：
```json
{
  "content": "更新后的消息内容"
}
```

#### 2. 删除单条消息
```
DELETE /api/sessions/{session_id}/messages/{message_index}
```

#### 3. 批量删除消息
```
POST /api/sessions/{session_id}/messages/batch-delete
```
请求体：
```json
{
  "message_indices": [0, 2, 5]
}
```

### 新增数据模型
- `MessageUpdateRequest`：消息更新请求模型
- `BatchDeleteRequest`：批量删除请求模型

## 前端变更

### 组件更新

#### MessageList.vue
增加的功能：
- 顶部工具栏，包含批量操作按钮
- 消息编辑界面（textarea + 保存/取消按钮）
- 消息操作按钮（编辑/删除）
- 批量选择复选框
- 批量操作工具栏（全选/删除选中）

新增属性：
- `currentSessionId`：当前会话 ID（用于 API 调用）

新增事件：
- `message-updated`：消息更新后触发
- `message-deleted`：单条消息删除后触发
- `messages-deleted`：批量删除后触发

#### ChatView.vue
增加的功能：
- 传递 `currentSessionId` 给 MessageList
- 处理消息更新/删除事件，重新加载消息和会话列表

新增方法：
- `handleMessageUpdated()`：处理消息更新
- `handleMessageDeleted()`：处理消息删除

## 使用指南

### 编辑消息
1. 将鼠标悬停在要编辑的消息上
2. 点击出现的"编辑"按钮（铅笔图标）
3. 在文本框中修改消息内容
4. 点击"保存"按钮（或按 Ctrl+Enter）保存修改
5. 点击"取消"按钮（或按 Esc）取消编辑

### 删除单条消息
1. 将鼠标悬停在要删除的消息上
2. 点击出现的"删除"按钮（垃圾桶图标）
3. 在确认对话框中点击"确定"

### 批量删除消息
1. 点击顶部的"批量操作"按钮进入批量模式
2. 勾选要删除的消息
3. 点击"删除选中"按钮
4. 在确认对话框中点击"确定"
5. 删除完成后会自动退出批量模式

## 技术细节

### 消息索引
- 消息索引从 0 开始，按在会话中的顺序排列
- 删除操作使用倒序删除，避免索引变化导致的问题

### 数据持久化
- 所有消息操作都会自动保存到存储（sessions.json）
- 会话的 `updated_at` 时间戳会自动更新

### 错误处理
- 无效的消息索引会返回 400 错误
- 会话不存在会返回 404 错误
- 前端会显示友好的错误提示

## 快捷键

- **Ctrl + Enter**：保存消息编辑
- **Esc**：取消消息编辑

## 注意事项

1. 编辑或删除消息后，会话列表会自动刷新，更新时间等信息
2. 批量删除时，如果选中的消息包含无效索引，整个操作会失败
3. 消息内容不能为空，保存时会验证
4. 正在输出的消息（AI 回复中）不显示操作按钮
