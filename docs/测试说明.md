# 语音识别修复和测试说明

## ✅ 问题已修复

**问题：** 调用火山引擎进行语音识别时显示"识别失败: 识别失败，请确保说话清晰"

**原因：** WebSocket 连接参数 `additional_headers` 不兼容导致连接失败

**修复：** 已将参数改为标准的 `extra_headers`，兼容更多版本

**修复文件：** `backend/utils/asr_demo.py` (第 277-291 行)

### 测试步骤

1. 在浏览器中打开前端地址（通常是 `http://localhost:5173`）
2. 点击页面右下角的 🎤 **麦克风按钮**
3. **说话**（建议说话时间：1-3 秒）
4. **释放按钮**
5. 等待识别结果显示在输入框中

### 注意事项

- ⚠️ 录音时长建议至少 1-2 秒
- ⚠️ 说话要清晰，环境尽量安静
- ⚠️ 确保浏览器已授予麦克风权限
- ⚠️ 首次使用时浏览器会请求麦克风权限，请允许

## 🔍 问题排查

### 如果语音识别仍然失败

#### 1. 查看日志

```bash
# 查看语音识别日志（最近 50 行）
tail -50 backend/logs/asr_$(date +%Y-%m-%d).log

# 查看 API 日志（最近 50 行）
tail -50 backend/logs/api_$(date +%Y-%m-%d).log
```

#### 2. 检查配置

```bash
python3 backend/test/test_config.py
```

确保所有配置项都显示 ✅

#### 3. 测试网络连接

```bash
# 测试是否可以访问火山引擎服务
curl -v wss://openspeech.bytedance.com/api/v2/asr 2>&1 | grep "Connected"
```

#### 4. 常见问题和解决方案

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 识别失败 | 配置错误 | 检查 `config.py` 中的 appid 和 token |
| 连接失败 | 网络问题 | 检查防火墙，确认可以访问火山引擎服务 |
| 无法录音 | 权限问题 | 确认浏览器已授予麦克风权限 |
| 识别为空 | 录音太短 | 录音时长至少 1-2 秒 |
| WebSocket 错误 | 依赖问题 | 运行 `pip install --upgrade websockets` |
