## 新功能说明

### 1. 树形对话结构

现在每条消息可以有多个子消息，支持：
- 从任意历史消息继续对话
- 同一个问题生成多个回复分支（并行响应）
- 对话路径可视化和回溯

### 2. 动态 System Prompt

可以在对话中途插入系统提示词，改变后续回复的风格：

```javascript
// 插入动态 System Prompt
POST /sessions/{session_id}/system-prompt
{
  "parent_id": "msg_xxx",
  "content": "现在请用英语回答"
}
```

### 3. 模型信息追踪

每条 AI 回复都记录：
- 使用的模型 ID 和提供商
- Token 使用量（prompt/completion/total）
- 响应延迟（毫秒）
- 是否为并行响应

### 4. 性能优化

- **会话列表加载**：只加载索引，速度提升约 10 倍
- **按需加载**：只有打开会话时才加载完整消息
- **按月分组**：便于归档和管理历史会话

## 使用方法

### 后端已自动适配，无需额外配置

### 前端需要适配的地方

1. **消息渲染**：使用 `msg.id` 而非数组索引
2. **消息操作**：更新/删除使用 `message_id`
3. **发送消息**：可选传递 `parent_id` 实现分支
4. **显示增强**：展示模型信息、Token 统计等

### 示例：从某条消息继续对话

```javascript
// 前端发送请求
fetch('/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    message: "继续这个话题",
    parent_id: "msg_uuid_002"  // 从这条消息分支
  })
})
```
