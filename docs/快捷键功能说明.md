# 快捷键功能说明

## 功能概述

新增了一个局部快捷键来控制录音功能的开关，无需全局热键权限，在前端页面中即可使用。

## 配置位置

快捷键配置在 `config.py` 文件中：

```python
HOTKEY_CONFIG = {
    "toggle": "ctrl+8",          # 全局快捷键（需要辅助功能权限）
    "local_toggle": "ctrl+r",    # 局部快捷键（在前端页面中使用，无需权限）
}
```

## 使用方法

### 默认快捷键：Ctrl+R

1. 打开前端页面（浏览器）
2. 按下 `Ctrl+R` 开始录音
3. 再次按下 `Ctrl+R` 停止录音并自动识别

### 自定义快捷键

可以在 `config.py` 中修改 `local_toggle` 的值，支持以下组合：

- `"ctrl+r"` - Ctrl+R（默认）
- `"ctrl+space"` - Ctrl+Space
- `"alt+r"` - Alt+R
- `"shift+space"` - Shift+Space
- `"ctrl+alt+r"` - Ctrl+Alt+R
- 等等...

## 功能特点

1. **无需权限**：不需要系统辅助功能权限，在浏览器中直接使用
2. **阻止默认行为**：会自动阻止浏览器的默认行为（如 Ctrl+R 的刷新）
3. **动态配置**：从后端读取配置，修改 config.py 后重启服务即可生效
4. **友好提示**：首次使用时会显示快捷键提示

## 实现细节

### 后端修改

1. **config.py**：添加了 `local_toggle` 配置项
2. **routes.py**：在 `/api/config` 端点中返回快捷键配置

### 前端修改

1. **ChatView.vue**：
   - 添加了键盘事件监听（`handleKeyDown`）
   - 实现了快捷键解析功能（`parseHotkey`）
   - 在组件挂载时注册事件监听
   - 在组件卸载时移除事件监听
   - 首次使用时显示快捷键提示

## 测试方法

1. 启动后端服务：`./start.sh`
2. 打开浏览器访问前端页面
3. 按下 `Ctrl+R` 测试录音功能
4. 观察页面提示和录音状态变化

## 注意事项

1. 快捷键只在前端页面获得焦点时有效
2. 某些浏览器可能会拦截特定的快捷键组合
3. 建议使用不与浏览器默认快捷键冲突的组合
4. 修改配置后需要重启后端服务才能生效
