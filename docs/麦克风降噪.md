# 麦克风降噪

录音时，后端将 PyAudio 采集到的 16 kHz、单声道、16 位 PCM 先交给开源
[`noisereduce`](https://github.com/timsainb/noisereduce) 的非平稳谱门算法，再送往流式语音识别。
保存的 WAV 使用同一份处理后的音频。单独录音功能也会处理保存的音频。

在项目虚拟环境安装依赖：

```bash
.venv/bin/python -m pip install -r requirements.txt
```

默认开启，默认强度为 `0.3`。可在 `.env.local` 中调整：

```dotenv
AUDIO_NOISE_REDUCTION=true
AUDIO_NOISE_REDUCTION_STRENGTH=0.3
```

强度范围是 `0` 到 `1`。值越大通常压低噪声越多，也越可能削弱较远的说话声。
设置 `AUDIO_NOISE_REDUCTION=false` 可用于录音对比。降噪仅处理噪声；另一台电脑外放
形成的房间反射、扬声器失真，以及麦克风距离带来的清晰度损失，不能保证恢复成内录效果。
