# 多模型视图切换 - 快速上手

## 功能简介

当你使用多个模型并行回答时，现在可以自由切换显示模式，让你更方便地查看和对比不同模型的回答。

## 快速开始

### 第一步：启用多模型并行

1. 打开会话设置（点击右上角的设置图标）
2. 在"模型选择"中选择多个模型
3. 保存设置

### 第二步：发送消息

发送一条消息后，你会看到所有选中的模型同时开始回答。

### 第三步：切换视图

在多模型回答的顶部，你会看到一排按钮，每个按钮对应一个模型。

## 三种操作方式

### 方式一：点击模型按钮切换

```
[GPT-4] [Claude] [Gemini]  ← 点击任意按钮
    ↓
[GPT-4] [Claude] [Gemini] [显示全部]  ← 只显示选中的模型
```

**效果**：
- 只显示你选择的那个模型的回答
- 回答区域自动扩展到最大宽度
- 其他模型的回答被隐藏

### 方式二：点击"显示全部"返回

```
[GPT-4] [Claude] [Gemini] [显示全部]  ← 点击这个按钮
    ↓
[GPT-4] [Claude] [Gemini]  ← 所有模型并排显示
```

**效果**：
- 返回并排显示所有模型
- 可以同时看到所有回答

### 方式三：点击卡片上的全屏按钮

```
┌─────────────┐
│   GPT-4     │
│   回答内容   │
│   [📋] [⛶]  │ ← 点击全屏按钮
└─────────────┘
```

**效果**：
- 直接进入该模型的全屏视图
- 与点击顶部模型按钮效果相同

## 使用技巧

### 技巧 1：快速对比

1. 默认并排显示，一眼看到所有回答
2. 发现某个回答特别好？点击它的按钮查看详情
3. 想看其他的？直接点击其他模型按钮切换

### 技巧 2：深度阅读

1. 对于长文本回答，点击模型按钮进入全屏
2. 专注阅读，不被其他回答干扰
3. 读完后点击"显示全部"返回对比

### 技巧 3：逐个查看

1. 点击第一个模型按钮
2. 仔细阅读该模型的回答
3. 点击第二个模型按钮切换到下一个
4. 重复直到看完所有模型

## 视觉提示

### 按钮状态

| 状态 | 外观 | 含义 |
|------|------|------|
| 正常 | 白色背景 | 未选中，可点击切换 |
| 高亮 | 蓝色边框 + 浅蓝背景 | 当前选中的模型 |
| 半透明 | 灰色半透明 | 其他未选中的模型 |

### 卡片状态

| 状态 | 外观 | 含义 |
|------|------|------|
| 并排 | 标准宽度，并排显示 | 所有模型同时可见 |
| 全屏 | 最大宽度，蓝色边框 | 单个模型全屏显示 |

## 常见问题

### Q: 如何返回并排显示？

A: 有两种方式：
1. 点击绿色的"显示全部"按钮
2. 再次点击当前高亮的模型按钮

### Q: 可以同时全屏显示多个模型吗？

A: 不可以。全屏模式一次只能显示一个模型，这样可以让你专注阅读。

### Q: 全屏模式下可以复制内容吗？

A: 可以！悬停在回答上，点击复制按钮即可。

### Q: 这个功能会影响单模型回答吗？

A: 不会。如果你只选择了一个模型，显示方式和之前完全一样。

### Q: 切换视图会重新加载回答吗？

A: 不会。所有回答都已经加载完成，切换视图只是改变显示方式，非常快速。
