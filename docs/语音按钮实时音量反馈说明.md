# 语音按钮实时音量反馈说明

## 功能概述

实现了语音按钮的实时音量反馈效果：根据麦克风收音的音量大小，动态调整波纹的扩散速度和透明度。

## 视觉效果

### 无声音时
- 波纹扩散**很慢**
- 透明度**较低**（30%）
- 几乎静止的感觉

### 有声音时
- 波纹扩散**快速**
- 透明度**较高**（根据音量 30%-100%）
- 扩散范围更大（1.3-2.1倍）

### 声音越大
- 波纹速度越快
- 透明度越高
- 扩散范围越大

## 技术实现

### 1. Web Audio API 音量分析

```javascript
// 创建音频分析器
audioContext = new AudioContext()
analyser = audioContext.createAnalyser()
analyser.fftSize = 256
analyser.smoothingTimeConstant = 0.8

// 分析音量
analyser.getByteFrequencyData(dataArray)
const average = sum / dataArray.length
const normalizedVolume = Math.min(average / 128, 1)

// 平滑过渡（避免突变）
audioVolume.value = audioVolume.value * 0.7 + normalizedVolume * 0.3
```

### 2. CSS 变量动态控制

```css
/* 根据音量调整动画速度 */
animation-duration: calc(1.5s / max(var(--volume, 0.1), 0.3));

/* 根据音量调整透明度 */
opacity: calc(0.3 + var(--volume, 0) * 0.7);

/* 根据音量调整扩散范围 */
transform: scale(calc(1.3 + var(--volume, 0) * 0.8));
```

### 3. 音频设置优化

```javascript
navigator.mediaDevices.getUserMedia({ 
  audio: {
    echoCancellation: true,    // 回声消除
    noiseSuppression: true,     // 噪声抑制
    autoGainControl: true       // 自动增益控制
  }
})
```

## 关键特性

### 1. 实时响应
- 使用 `requestAnimationFrame` 实现 60fps 刷新
- 音量变化延迟 < 50ms

### 2. 平滑过渡
- 使用加权平均避免突变：`new = old * 0.7 + current * 0.3`
- 视觉效果流畅自然

### 3. 灵敏度调优
- `smoothingTimeConstant = 0.8`：平滑音频数据
- 归一化到 0-1 范围：`average / 128`
- 最小值保护：`max(volume, 0.3)`，确保总有微弱动画

### 4. 降级处理
- 如果无法获取音频流，使用默认固定动画
- 不影响正常录音功能
- 控制台警告而非错误

   - 系统请求麦克风权限

2. **观察波纹效果**

## 调优参数

如果需要调整灵敏度，可以修改以下参数：

```javascript
// 音频分析器灵敏度
analyser.fftSize = 256              // 256/512/1024/2048
analyser.smoothingTimeConstant = 0.8 // 0-1，越大越平滑

// 音量归一化
const normalizedVolume = average / 128  // 调整除数改变灵敏度

// 平滑系数
audioVolume.value = old * 0.7 + new * 0.3  // 调整权重改变响应速度

// 动画速度范围
animation-duration: calc(1.5s / max(var(--volume), 0.3))
// 0.3 = 最慢速度，调小更慢，调大更快

// 扩散范围
transform: scale(calc(1.3 + var(--volume) * 0.8))
// 1.3 = 最小范围，0.8 = 最大增量
```

## 常见问题

### Q: 为什么波纹不动？
A: 可能原因：
1. 浏览器未授予麦克风权限
2. 麦克风被其他应用占用
3. 检查控制台是否有警告信息

### Q: 波纹反应太慢/太快？
A: 调整 `smoothingTimeConstant` 参数：
- 更快响应：降低到 0.5-0.7
- 更慢响应：提高到 0.85-0.95

### Q: 波纹总是很剧烈？
A: 调整归一化参数：
- 增大除数：`average / 256`
- 或降低权重：`new * 0.2`
