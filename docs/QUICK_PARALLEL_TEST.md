## 🎯 关键验证点

### ✅ 1. 同时开始
- [ ] 所有模型卡片几乎同时出现（0-2秒内）
- [ ] 不是一个接一个出现

### ✅ 2. 同时流式
- [ ] 所有卡片同时开始逐字显示内容
- [ ] 可以看到文字逐渐增加（不是一次性全部显示）
- [ ] 每个卡片独立更新（不会互相等待）

### ✅ 3. 独立完成
- [ ] 某个模型完成后，其他模型继续显示
- [ ] 不会等所有模型都完成才一起显示

### ✅ 4. 刷新持久化
- [ ] 刷新页面后，消息仍然是横向卡片布局
- [ ] 所有内容完整保留

## 🐛 如果出现问题

### 问题1：卡片是纵向排列的
**原因**：可能是旧数据格式
**解决**：
1. 创建新会话
2. 重新配置多模型
3. 发送新消息测试

### 问题2：一个接一个显示（不是同时）
**原因**：可能后端没有使用新的并行代码
**解决**：
1. 检查后端日志：`🚀 并行调用 X 个模型`
2. 如果没有这条日志，重启后端
```bash
# 停止旧进程
pkill -f "uvicorn"
pkill -f "python.*main.py"

# 重新启动
./start.sh
```

### 问题3：没有流式效果（一次性全部显示）
**原因**：可能网络缓存或前端代码问题
**解决**：
1. 硬刷新浏览器：Cmd+Shift+R (Mac) 或 Ctrl+Shift+R (Windows)
2. 清除浏览器缓存
3. 打开隐私模式测试

### 问题4：只显示单个模型
**原因**：会话配置没有保存
**解决**：
1. 打开会话设置
2. 确认已选择多个模型
3. 点击"保存"
4. 等待提示"会话配置已保存"
5. 刷新页面
6. 重新打开设置确认配置已保存

## 📊 性能对比

### 测试数据（示例）

#### 顺序模式（旧）❌
```
模型1：开始 0s  → 完成 10s
模型2：开始 10s → 完成 20s  (等待10秒)
模型3：开始 20s → 完成 30s  (等待20秒)
────────────────────────────
总耗时：30秒
```

#### 并行模式（新）✅
```
模型1：开始 0s → 完成 10s
模型2：开始 0s → 完成 12s  (同时开始)
模型3：开始 0s → 完成 9s   (同时开始)
────────────────────────────
总耗时：12秒（最慢的那个）
```

**速度提升**：30秒 → 12秒 = **2.5倍** ⚡
