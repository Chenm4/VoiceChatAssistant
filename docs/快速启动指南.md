## 🎯 前端启动步骤

### 1. 打开终端，进入前端目录
```bash
cd frontend
```

### 2. 启动开发服务器
```bash
npm run dev
```

应该看到：
```
VITE v5.x.x  ready in xxx ms
➜  Local:   http://localhost:5173/
```

### 3. 打开浏览器
访问: http://localhost:5173

### 4. 清除缓存（重要！）
**方式1**: 在浏览器中按 `Ctrl+Shift+Delete` (Windows) 或 `Cmd+Shift+Delete` (Mac)

**方式2**: 打开开发者工具(F12)，在 Network 标签勾选 "Disable cache"

## 🔍 问题排查

### 如果前端无法连接后端

1. 检查后端是否运行:
```bash
curl http://localhost:8888/api/sessions
```

2. 查看后端日志:
```bash
tail -f /tmp/backend_clean.log
```

3. 重启后端:
```bash
pkill -f "backend.main"
cd /Users/hb952/code/yuyinshibie
python3 -m backend.main > /tmp/backend.log 2>&1 &
```

### 如果编辑/删除功能报错

1. 清除浏览器缓存
2. 刷新页面 (F5 或 Cmd+R)
3. 重启前端服务器 (Ctrl+C 后重新运行 `npm run dev`)

### 查看浏览器控制台

按 F12 打开开发者工具，查看：
- **Console** 标签 - 查看JavaScript错误
- **Network** 标签 - 查看API请求和响应
