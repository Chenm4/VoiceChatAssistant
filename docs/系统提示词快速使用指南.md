# 系统提示词快速使用指南

## 🚀 快速开始（3步完成配置）

### 步骤1: 打开会话设置
1. 在聊天界面右上角点击 **⚙️ 设置按钮**
2. 会话设置侧边栏会从右侧滑出

### 步骤2: 选择系统提示词
找到"系统提示词"区域，你有三种方式：

#### 方式A：使用预设模板（推荐新手）
1. 点击下拉菜单
2. 选择一个预设模板（如"编程专家"）
3. 系统会自动填充对应的提示词内容

#### 方式B：自定义提示词（推荐高级用户）
1. 点击下拉菜单选择"自定义..."
2. 在文本框中输入你的系统提示词
3. 示例：`你是一个专注于前端开发的技术专家，擅长 Vue.js 和 React`

#### 方式C：清除提示词（使用默认行为）
1. 点击下拉菜单选择"无（使用默认）"
2. AI将使用模型的默认行为

### 步骤3: 保存配置
点击侧边栏底部的 **"保存会话配置"** 按钮

✅ 完成！你的下一条消息将使用新的系统提示词

## 💡 实用技巧

### 技巧1: 组合使用预设 + 自定义
1. 先选择一个接近的预设模板
2. 在文本框中微调内容
3. 添加你的特殊要求

**示例**：
```
你是一个资深的软件工程师，擅长多种编程语言和框架。
请用简洁、专业的方式回答技术问题，并在必要时提供代码示例。

【自定义补充】
特别注意：我主要使用 Python 和 Vue.js，请优先使用这些技术栈的例子。
```

### 技巧2: 不同任务创建不同会话
- **编程会话**：使用"编程专家"模板
- **写作会话**：使用"写作助手"模板
- **学习会话**：使用"数学导师"或"英语老师"模板

### 技巧3: 配合温度参数调整
- **创意任务**（写作、头脑风暴）→ 温度 0.8-1.2
- **技术问题**（代码、数学）→ 温度 0.3-0.7
- **事实查询**（定义、翻译）→ 温度 0.1-0.3

### 技巧4: 使用限制性指令
在系统提示词中明确不要做什么：
```
你是一个编程助手。
- 请直接提供代码，不要过度解释原理
- 不要提供多个方案，只给最佳实践
- 代码必须可以直接运行
```

## ⚠️ 注意事项

### 1. Token 消耗
系统提示词会作为每次请求的一部分发送，较长的系统提示词会增加 Token 消耗。

**建议**：
- 保持系统提示词简洁（100-200字为宜）
- 不要重复说明同一件事
- 去掉不必要的客套话

### 2. 模型兼容性
所有支持 OpenAI API 格式的模型都支持系统提示词，但效果可能有差异：
- GPT-4：效果最好，严格遵循系统提示词
- GPT-3.5：效果良好，偶尔会偏离
- 其他模型：效果因模型而异

### 3. 实时生效
修改系统提示词后：
- ✅ 新的对话会使用新的系统提示词
- ❌ 已有的对话历史不会改变
- 💡 如需重置对话，可以创建新会话

### 4. 多模型并行
如果选择了多个模型并行响应，相同的系统提示词会发送给所有模型。

## 🐛 常见问题

### Q: 为什么修改系统提示词后，AI 的回答没有明显变化？
**A**: 可能的原因：
1. 系统提示词不够明确 → 使用更具体的指令
2. 模型能力限制 → 尝试更强大的模型（如 GPT-4）
3. 历史对话的影响 → 创建新会话测试

### Q: 可以为不同的对话分支设置不同的系统提示词吗？
**A**: 暂不支持。系统提示词是会话级别的，整个会话使用同一个系统提示词。

### Q: 系统提示词可以多长？
**A**: 技术上无限制，但建议：
- 简单任务：50-100字
- 复杂任务：100-300字
- 超过500字通常没有必要

### Q: 我的自定义系统提示词会被保存吗？
**A**: 会的！系统提示词会随会话配置一起保存，下次打开会话时会自动加载。
