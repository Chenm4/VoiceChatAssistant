## 🚀 使用方法

### 1. 解压文件

```bash
# 解压压缩包
tar -xzf yuyinshibie_20260201_003219.tar.gz

# 进入目录
cd yuyinshibie_20260201_003219
```

### 2. 安装依赖

#### 后端依赖

```bash
# 安装 Python 依赖
pip install -r requirements.txt
```

**依赖列表**:
- fastapi
- uvicorn
- openai
- pyaudio
- aiohttp
- websockets
- python-multipart

#### 前端依赖

```bash
# 进入前端目录
cd frontend

# 安装 Node.js 依赖
npm install
```

### 3. 配置项目

编辑 `config.py` 文件，配置以下内容：

```python
# OpenAI API 配置
OPENAI_CONFIG = [
    {
        "name": "OpenAI",
        "api_key": "your-api-key",
        "models": ["gpt-4", "gpt-3.5-turbo"],
        "base_url": "https://api.openai.com/v1"
    }
]

# 字节跳动 ASR 配置
BYTEDANCE_ASR_CONFIG = {
    'app_key': 'your-app-key',
    'access_key': 'your-access-key',
    'url': 'wss://openspeech.bytedance.com/api/v3/sauc/bigmodel'
}

# 音频参数配置
AUDIO_CONFIG = {
    'rate': 16000,
    'channels': 1,
    'chunk': 1024
}
```

### 4. 启动项目

#### 方式一：使用启动脚本（推荐）

```bash
# 使用英文脚本
./start.sh

# 或使用中文脚本
./启动.sh
```

启动脚本会自动：
1. 启动后端服务（端口 8000）
2. 启动前端服务（端口 5173）
3. 自动打开浏览器

#### 方式二：手动启动

**启动后端**:
```bash
cd backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**启动前端**:
```bash
cd frontend
npm run dev
```

### 5. 访问应用

打开浏览器访问: http://localhost:5173

## 🐛 常见问题

### 1. 麦克风权限问题

**问题**: 浏览器无法访问麦克风

**解决方案**:
1. 检查浏览器麦克风权限设置
2. 确保使用 HTTPS 或 localhost
3. 重新加载页面并允许麦克风访问

### 2. 端口占用问题

**问题**: 端口 8000 或 5173 被占用

**解决方案**:
```bash
# 查找占用端口的进程
lsof -i :8000
lsof -i :5173

# 杀死进程
kill -9 <PID>

# 或修改端口
# 后端：在 start.sh 中修改 --port 参数
# 前端：在 frontend/vite.config.js 中修改 server.port
```

### 3. 依赖安装失败

**问题**: pip install 或 npm install 失败

**解决方案**:
```bash
# Python 依赖
pip install --upgrade pip
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# Node.js 依赖
npm install --registry=https://registry.npmmirror.com
```

### 4. PyAudio 安装失败

**问题**: PyAudio 安装报错

**解决方案**:

**macOS**:
```bash
brew install portaudio
pip install pyaudio
```

**Ubuntu/Debian**:
```bash
sudo apt-get install portaudio19-dev
pip install pyaudio
```

**Windows**:
```bash
# 下载预编译的 wheel 文件
# https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
pip install PyAudio-xxx.whl
```

### 5. ASR 识别失败

**问题**: 语音识别不工作

**解决方案**:
1. 检查 `config.py` 中的 ASR 配置
2. 确认 API 密钥正确
3. 检查网络连接
4. 查看后端日志
