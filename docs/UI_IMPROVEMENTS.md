# UI 改进说明

本次更新对界面和交互进行了全面优化，移除了紫色配色，简化了批量操作流程，提升了用户体验。

## 主要改进

### 1. 配色方案优化 ✨

**移除紫色，采用蓝色/绿色/红色方案：**
- 🔵 **蓝色**：主要交互元素（用户消息气泡、按钮、链接等）
- 🟢 **绿色**：AI助手、麦克风按钮（未录音状态）、成功操作
- 🔴 **红色**：删除操作、麦克风按钮（录音中状态）

**具体修改：**
- 用户消息气泡：紫色渐变 → 蓝色渐变 (#3b82f6 → #2563eb)
- AI助手头像：灰色 → 绿色渐变 (#10b981 → #059669)
- 麦克风按钮：紫色 → 绿色（未录音）/ 红色（录音中）
- 新建会话按钮：紫色 → 蓝色
- 发送按钮：紫色 → 蓝色
- 选中状态：紫色背景 → 蓝色背景
- 所有聚焦状态：紫色边框 → 蓝色边框

### 2. 消息操作优化 🎯

**简化的操作流程：**
- 移除了"批量操作"模式切换按钮
- 每条消息始终显示复选框（用户消息右侧，AI消息左侧）
- 删除时其他消息的选中状态保持不变
- 顶部工具栏只有"全选"和"删除选中"两个按钮

**操作按钮位置调整：**
- 操作按钮（复制、编辑、删除）移到消息内容左侧
- 垂直排列的图标按钮，悬停时显示
- 更直观的操作反馈

**新增复制功能：**
- 每条消息添加复制按钮
- 点击后图标变为对勾，1秒后恢复
- 支持快速复制消息内容到剪贴板

### 3. 删除接口统一 🔧

**后端优化：**
- 移除单独的单条删除接口
- 统一使用 `/api/sessions/{session_id}/messages/delete` 接口
- 根据传入的 `message_indices` 数组长度自动判断是删除单条还是多条
- 简化了API结构，减少了代码冗余

**前端适配：**
- 删除单条消息时传入单元素数组 `[index]`
- 批量删除时传入多元素数组 `[index1, index2, ...]`
- 使用统一的 `deleteMessages()` 方法处理所有删除操作

### 4. 视觉改进 🎨

**消息布局优化：**
```
AI消息：[☑] [🤖] [📝复制 ✏️编辑 🗑️删除] 消息内容...
用户消息：消息内容... [📝复制 ✏️编辑 🗑️删除] [👤] [☑]
```

**按钮样式改进：**
- 操作按钮改为方形图标按钮（28x28px）
- 删除按钮悬停时显示红色背景
- 编辑/保存按钮使用更大的尺寸（36x36px）

**选中状态视觉：**
- 选中的消息显示淡蓝色背景
- 复选框使用蓝色主题色

### 5. 交互体验提升 ⚡

**更流畅的操作：**
- 按钮悬停时有放大效果（transform: scale(1.05)）
- 点击操作有即时的视觉反馈
- 编辑框有明显的蓝色边框

**智能反馈：**
- 复制成功时图标变化
- 删除前有确认对话框
- 批量操作显示选中数量

## 详细修改清单

### 后端修改

#### `backend/api/routes.py`
- 移除 `DELETE /sessions/{session_id}/messages/{message_index}` 接口
- 重命名并优化批量删除接口为 `POST /sessions/{session_id}/messages/delete`
- 支持单条和多条消息的统一删除

### 前端修改

#### `frontend/src/components/MessageList.vue`
**布局调整：**
- 重构消息列表结构，使用 `.message-row` 和 `.message-content-wrapper`
- 操作按钮移到 `.message-actions-left`，位于消息内容左侧
- 复选框始终显示，不依赖批量模式

**功能增强：**
- 添加 `copyMessage()` 复制功能
- 统一 `deleteMessages()` 方法处理所有删除
- 移除 `toggleBatchMode()` 和 `isBatchMode` 相关逻辑

**样式更新：**
- 用户消息气泡：蓝色渐变
- AI助手头像：绿色渐变
- 选中状态：蓝色背景
- 按钮悬停效果优化

#### `frontend/src/components/VoiceButton.vue`
- 未录音状态：绿色渐变背景 (#10b981 → #059669)
- 录音状态：保持红色渐变
- 阴影颜色相应调整

#### `frontend/src/components/SessionSidebar.vue`
- 新建会话按钮：蓝色渐变
- 活动会话背景：蓝色渐变
- 悬停边框：蓝色
- 标题输入框焦点：蓝色边框

#### `frontend/src/components/InputArea.vue`
- 输入框焦点边框：蓝色
- 发送按钮激活状态：蓝色渐变
- 阴影颜色调整

## 配色规范

### 主色调
```css
/* 蓝色 - 主要交互 */
--primary-blue: #3b82f6;
--primary-blue-dark: #2563eb;

/* 绿色 - 成功/AI */
--success-green: #10b981;
--success-green-dark: #059669;

/* 红色 - 删除/警告 */
--danger-red: #ef4444;
--danger-red-dark: #dc2626;
```

### 使用场景
- **蓝色**：用户消息、按钮、选中状态、链接、焦点状态
- **绿色**：AI助手、麦克风（待机）、保存按钮、成功提示
- **红色**：删除按钮、麦克风（录音）、取消按钮、错误提示
