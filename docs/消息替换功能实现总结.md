## 技术架构

### 数据流

```
用户点击"编辑并重新生成"
    ↓
前端 MessageList 设置 willRegenerateAfterEdit = true
    ↓
用户修改内容并保存
    ↓
触发 regenerate 事件 → ChatView.handleRegenerateMessage()
    ↓
POST /api/sessions/{session_id}/messages/{message_id}/regenerate
    ↓
后端 routes.regenerate_message()
    ↓
1. 更新消息内容
2. 删除子消息
3. 构建消息历史
4. 调用 AI 模型（流式）
    ↓
SSE 流式响应 → 前端实时更新
    ↓
完成后重新加载会话消息
```

### 消息树结构

```
Root
 ├─ User Message 1 (id: msg_001)
 │   └─ AI Response 1 (id: msg_002)
 │       └─ User Message 2 (id: msg_003)  ← 修改这条
 │           └─ AI Response 2 (id: msg_004)  ← 会被删除
 │               └─ User Message 3 (id: msg_005)  ← 会被删除
 │                   └─ AI Response 3 (id: msg_006)  ← 会被删除
```

修改 `msg_003` 后：
```
Root
 ├─ User Message 1 (id: msg_001)
 │   └─ AI Response 1 (id: msg_002)
 │       └─ User Message 2 (id: msg_003) ← 内容已更新
 │           └─ AI Response 2 (id: msg_007) ← 新生成的响应
```

## 关键代码片段

### 后端：删除子消息并更新

```python
# 删除该消息的所有子消息（递归删除）
all_ids_to_delete = set()
for child_id in target_message.children_ids:
    all_ids_to_delete.add(child_id)
    all_ids_to_delete.update(collect_descendant_ids(session, child_id))

# 清空子消息列表
target_message.children_ids = []

# 从会话中删除这些消息
session.messages = [msg for msg in session.messages if msg.id not in all_ids_to_delete]
```

```javascript
const reader = response.body.getReader()
const decoder = new TextDecoder()
let buffer = ''

while (true) {
  const { done, value } = await reader.read()
  if (done) break
  
  buffer += decoder.decode(value, { stream: true })
  const lines = buffer.split('\n')
  buffer = lines.pop() || ''
  
  for (const line of lines) {
    processLine(line)
  }
}
```

## 已知限制和解决方案

### 限制 1：无法撤销删除
**影响：** 修改消息后，后续对话无法恢复

**计划解决方案：**
- 实现消息版本管理
- 添加撤销功能
- 自动备份机制

---

### 限制 2：不支持 AI 消息编辑
**影响：** 只能修改用户消息

**计划解决方案：**
- 添加 AI 消息的"重新生成"功能
- 支持 AI 消息的分支编辑

---

### 限制 3：批量修改不支持
**影响：** 一次只能修改一条消息

**计划解决方案：**
- 实现批量编辑界面
- 支持选择多条消息同时重新生成
