# 浏览器录音与语音凭据

网页录音使用当前浏览器的麦克风，通过已认证的 `/api/recording/browser` WebSocket 上传单声道 16kHz PCM16。浏览器按 200ms 分段，最多四段在途并等待逐段 ACK；积压超过两秒时停止并提示网络异常，不静默丢弃录音。服务端复用 StreamingASR 的识别、音量、WAV 保存和当前账号会话归属。原有服务器本地录音接口仍保留。

浏览器需要 HTTPS 和麦克风权限。设备列表来自浏览器；USB 声卡必须连接到访问网页的电脑。双路模式混合两个已选择且不同的输入设备，切换来源时保持同一条识别连接。页面关闭或连接中断会停止采音，并清理当前连接拥有的识别实例。

设置中的“语音识别与豆包配置”可以选择 Soniox 或火山 ASR，并查看、编辑各自凭据及豆包 App ID、Access Token。全部配置仅写入当前登录账号的 `settings.json`；保存后新录音生效，无需重启。没有配置密钥时会在开始录音前提示，不再尝试打开服务器麦克风。普通模型 API Key 同样可以点击“查看”显示原文，再次点击隐藏。

豆包窗口默认关闭，用户主动点击聊天页“豆包”后开启。豆包凭据与 ASR 凭据相互独立。

回归用例：`backend/test/test_browser_recording.py`、`frontend/test/pcmCapture.test.js`。测试与部署需要按用户授权范围执行；推送源码不会自动更新已发布的静态资源或重启服务。
