# LobeHub 本地开发启动指南

## 快速开始

### 1. 启动 Docker 服务

确保 Docker Desktop 正在运行，然后执行：

```bash
# 启动所有必需的服务（PostgreSQL, Redis, MinIO, Casdoor, SearXNG）
docker-compose -f docker-compose.development.yml up -d
```

这将启动以下服务：
- **PostgreSQL** (端口 5432) - 数据库
- **Redis** (端口 6379) - 缓存
- **MinIO** (端口 9000/9001) - 文件存储
- **Casdoor** (端口 8000) - 认证服务
- **SearXNG** (端口 8080) - 搜索服务

### 2. 检查服务状态

```bash
# 查看所有服务运行状态
docker-compose -f docker-compose.development.yml ps

# 查看服务日志（如果有问题）
docker-compose -f docker-compose.development.yml logs -f
```

### 3. 运行数据库迁移

```bash
# 安装依赖（如果还没安装）
pnpm install

# 执行数据库迁移
pnpm db:migrate
```

预期输出：`✅ database migration pass.`

### 4. 启动开发服务器

```bash
pnpm dev
```

服务器将在 `http://localhost:3010` 上启动

## 停止服务

```bash
# 停止所有 Docker 服务
docker-compose -f docker-compose.development.yml down

# 停止并删除所有数据（重置环境）
docker-compose -f docker-compose.development.yml down -v
```

## 管理界面

- **LobeHub 应用**: http://localhost:3010
- **MinIO 控制台**: http://localhost:9001 (用户名: admin, 密码: YOUR_RUSTFS_PASSWORD)
- **Casdoor 管理**: http://localhost:8000

## 常见问题

### 端口被占用

如果端口已被占用，可以修改 `docker-compose/local/.env` 中的端口配置：

```bash
# 检查端口占用
lsof -i :5432  # PostgreSQL
lsof -i :6379  # Redis
lsof -i :9000  # MinIO API
lsof -i :8000  # Casdoor
```

### 数据库连接失败

1. 确认 Docker 服务正在运行
2. 检查 `.env.local` 中的 `DATABASE_URL` 配置是否正确
3. 尝试重启 Docker 服务

### 重置所有数据

```bash
# 停止服务并删除所有卷
docker-compose -f docker-compose.development.yml down -v

# 重新启动
docker-compose -f docker-compose.development.yml up -d

# 重新运行迁移
pnpm db:migrate
```

## 配置文件说明

- `.env.local` - 本地开发环境变量（已配置好）
- `docker-compose/local/.env` - Docker 服务配置
- `docker-compose.development.yml` - Docker Compose 配置
